# EduNexa — Learn Without Limits

A responsive, multi-section educational notes website starter for RBSE, CBSE, other Indian boards, and college learners.

## Included in this project
- Responsive homepage and mobile navigation
- School classes 7–12 and college course discovery cards
- Searchable, filterable starter notes library
- Sample notes rendered in a readable dialog
- Local bookmarks (saved in the visitor's browser)
- Dark mode (saved in the visitor's browser)
- Four-question interactive practice quiz
- Custom EduNexa SVG logo
- No build step or package installation required

## Important: current scope
This is a working **front-end starter**, not yet a complete notes database or production account system. It includes 12 short starter resources. It does not yet have student login, cloud bookmarks, an admin upload dashboard, or complete official notes for every class/subject/university. Those need a secure backend and verified study content. Never collect passwords in a static-only site.

## Preview on a phone
1. Download and extract `EduNexa-Website.zip`.
2. Open `index.html` in a browser, or open the folder in an editor such as Acode.
3. For the best testing experience, preview the folder using the editor's preview/local server feature.

## Publish free using GitHub Pages
1. Sign in to GitHub and create a **public** repository named `edunexa`.
2. Upload the files and folders from this project (upload `index.html`, `styles.css`, `app.js`, `README.md`, and the `assets` folder; do not upload only the ZIP).
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Wait for the deployment to finish. For a user `YOUR-USERNAME`, the usual address is `https://YOUR-USERNAME.github.io/edunexa/`.
6. If the CSS/logo is missing, check that file names and the `assets` folder were uploaded with the same spelling.

GitHub Pages hosts static files. It does not run a server-side database or handle secure login on its own.
